무료급식 출석 시스템 사용법

명단을 등록한 뒤 QR로 출석을 처리하고, 월별 출석 일지에서 결과를 확인·정정·내보내는 서비스입니다.

시작 전 준비 서비스 흐름 관리자 업무 파일과 보관 문제 확인
01

시작 전 준비

서버와 태블릿이 같은 네트워크에서 연결되어 있어야 합니다.

1. 서버 실행

Windows PC에서 서버 JAR를 실행합니다. 서버가 켜진 뒤에 관리자 페이지와 QR 출석 기능을 모두 사용할 수 있습니다.

2. 주소 확인

서버를 실행한 관리자 PC에서 관리자 페이지를 엽니다. 주소는 http://localhost:8080입니다.

3. 명단 파일 준비

엑셀의 연번, 성명, 생년월일 열을 확인합니다. 등록할 명단 전체를 한 파일로 준비합니다.

02

서비스는 이렇게 흐릅니다

출석을 찍는 순간부터 기록이 남는 곳까지의 전체 흐름입니다.

  1. 관리자가 명단을 업로드합니다.

    업로드한 명단은 현재 출석 대상자의 기준 명단이 되며, 서버 메모리에도 즉시 반영됩니다.

  2. 이용자가 QR을 제시하고 태블릿이 스캔합니다.

    태블릿은 서버로 QR 정보를 전송하고, 서버는 현재 등록된 명단에서 대상자를 확인합니다.

  3. 서버가 해당 날짜에 출석 표시를 저장합니다.

    정상 처리되면 그 달의 출석 일지에서 해당 이용자·날짜 칸에 o가 기록됩니다. 같은 날 다시 찍으면 중복 출석으로 처리하지 않습니다.

  4. 태블릿에 확인 화면이 표시됩니다.

    서버의 응답을 받은 뒤 이용자 이름과 환영 문구가 화면에 나타납니다.

03

관리자 페이지에서 하는 일

명단 등록, 출석 확인, 수동 정정, 엑셀 내보내기를 한 화면에서 처리합니다.

명단 등록

새 명단 업로드

파일을 선택한 뒤 업로드하기를 누릅니다. 새 파일은 기존 대상자 명단 전체를 교체하므로, 일부 인원만 담긴 파일을 올리지 않도록 주의합니다.

출석 확인

날짜별 현황 조회

오른쪽 출석체크 현황에서 날짜를 선택하면 전체·출석·결석 수와 대상자별 상태를 확인할 수 있습니다.

수동 정정

출석 / 결석 버튼 누르기

대상자 오른쪽 상태 버튼을 누르면 결석 → 출석, 출석 → 결석으로 즉시 바뀝니다. 변경 사항은 해당 월 출석 일지에도 바로 저장됩니다.

보관·제출

엑셀 내보내기

원하는 날짜를 조회한 뒤 엑셀 내보내기를 누르면, 그 날짜가 속한 월의 출석 일지를 내려받을 수 있습니다.

04

파일은 두 종류로 관리됩니다

원본 명단과 실제 출석 기록을 혼동하지 않도록 구분합니다.

현재 대상자 명단

data/userlist/attendance-roster.xlsx

관리자 페이지에서 올린 명단입니다. QR 대상자를 찾기 위한 기준이며, 새 명단을 업로드하면 이 파일이 교체됩니다.

월별 출석 일지

data/attendance/무료급식 일일 식사내역_26.8_일지.xlsx

실제 출석 표시가 저장되는 파일입니다. 달이 바뀐 뒤 처음 출석·조회·관리하는 시점에 새 월 파일이 자동 생성되며, 이전 달 파일은 그대로 보관됩니다.

엑셀 직접 수정은 가급적 피하세요. 서버가 실행 중일 때에는 관리자 페이지의 상태 버튼으로 정정하는 방식이 안전합니다. 꼭 직접 수정해야 한다면 서버를 끄고 파일을 백업한 뒤 수정하세요.
05

문제가 생기면 먼저 확인하세요

대부분의 문제는 서버 실행 상태, 네트워크 주소, 엑셀 파일 열림 상태에서 확인할 수 있습니다.

QR을 찍었는데 화면이 바뀌지 않아요.

서버 PC가 실행 중인지, 태블릿이 같은 Wi-Fi에 연결되어 있는지, 태블릿에 설정한 서버 IP와 포트가 맞는지 확인하세요. 서버 창의 로그에 QR 요청과 처리 결과가 남습니다.

명단 업로드가 실패하거나 엑셀을 닫으라는 안내가 나와요.

Windows에서는 열려 있는 엑셀 파일이 잠길 수 있습니다. 현재 명단 또는 출석 일지를 열어 둔 엑셀 창을 모두 닫고, 잠시 후 다시 업로드하세요.

다음 달이 되었는데 새 파일을 따로 만들어야 하나요?

아닙니다. 다음 달에 처음 출석을 처리하거나 그 달을 조회하면 현재 명단을 기준으로 새 월 출석 일지가 자동 생성됩니다.

테스트로 찍은 출석을 지우고 싶어요.

관리자 페이지에서 해당 날짜를 선택한 뒤, 해당 이용자의 출석 버튼을 눌러 결석으로 바꾸세요. 그러면 출석 일지의 표시도 함께 지워집니다.
